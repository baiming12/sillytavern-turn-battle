# SillyTavern 回合战斗扩展（首版）

这是一个本地计算战斗的 SillyTavern 前端扩展。剧情 AI 只提交开战前的完整快照；战斗伤害、资源、行动、道具与胜负由扩展结算；结束后复制报告交给剧情 AI 续写。

## 安装

将整个 `sillytavern-turn-battle` 文件夹放入 SillyTavern 的 `public/scripts/extensions/third-party/`（供所有用户使用），或当前用户的 `data/<用户>/extensions/`，然后刷新酒馆页面。在扩展设置中打开“回合战斗”面板。当前版本需要支持 JavaScript ES module、`structuredClone` 的浏览器。

如果从 GitHub 安装，在手机酒馆依次打开“扩展 → 安装扩展”，粘贴本仓库的 GitHub 地址并安装。仓库名称应保持 `sillytavern-turn-battle`，因为扩展按这个路径加载设置页。

## 手机快速测试

1. 安装扩展后，打开一个单人角色卡的聊天，在“回合战斗 → 战斗”点“载入示例战斗并预览”，检查后点“确认开战”。示例战斗会临时读取基础测试包，不需要先导入或绑定。
2. 若要在自己的角色卡与剧情战斗中使用这些条目，到“内容包”点“载入基础测试包并预览”，检查后确认导入；再到“角色卡绑定”，把“基础战斗测试包”设为“整包”并保存。也可在“批量导入”上传 [`examples/基础测试内容包.json`](examples/基础测试内容包.json)。已导入旧测试包的用户可再次载入并选择更新，获取我方角色预设和各条目的剧情介绍。
3. 也可以用“手动粘贴战斗请求”填入 [`examples/基础测试开战快照.json`](examples/基础测试开战快照.json)，此方式仍需先完成内容包导入与角色卡绑定。
4. 示例有玩家前排战士、后排法师，以及敌方守卫、刺客、法师。玩家行动点用完后，点“结束玩家阶段，让敌方行动”；双方一方全员倒下时自动结算。提前中断需要二次确认。可试火球无视遮挡、剑击被前排遮挡、刺客突入、药剂、石灰粉、套绳、五件饰品、敌方 AI 和战后报告。
5. 如需测试剧情消息自动生成按钮，把“设置与提示词”中的剧情提示词放入预设，让剧情 AI 在回复末尾输出 `TURN_BATTLE_REQUEST` 标记。

## 基础西幻职业包

在“战斗”页点“载入西幻示例战斗”可立即试玩，不影响当前角色卡绑定。要用于自己的剧情，在“内容包”页点“载入西幻职业包并预览”，校验后导入，再到“角色卡绑定”启用整包或单独选择职业模板。单独选择模板会自动带上它当前引用的技能、装备和状态；日后新学的技能仍需在绑定中启用相应条目，或直接启用整包。

本包包含战士、射手、法师、狂战士、牧师、圣骑士、刺客七个我方模板、五个敌人模板、87 个技能和 32 个状态。技能按通用武技、通用与专属法术、敏捷技巧、职业专属、怪物通用分组。每个职业模板带两项永久被动；破甲、祝福、狂怒、迅捷、沉默、束足、中毒等由状态定义实际结算。中毒目前降低攻击属性，不会自动每回合扣血。治疗为固定恢复量。详见[完整技能与状态目录](examples/西幻技能目录.md)。

可直接导入[西幻职业内容包](examples/基础西幻职业技能包.json)和[西幻写卡助手世界书](examples/西幻写卡助手世界书.json)。若按当前角色卡绑定导出专用世界书，请在导入包并绑定后，从“设置与提示词”导出；同页复制新的剧情提示词放入预设。仓库里的 [西幻开战快照](examples/基础西幻开战快照.json)可用于手动预览。内容包及目录由 `npm run build:fantasy` 生成。

## 基本流程

1. 在“角色卡绑定”里为当前角色卡选择可用的内容包、类别或条目。内置 `core` 包是示例。
2. 在“设置与提示词”复制开战提示词，加入剧情预设。提示词包含当前角色卡启用的内容目录。
3. 当剧情将进入战斗时，AI 的本轮回复应停在第一项行动之前，在末尾输出 `TURN_BATTLE_REQUEST` HTML 注释及完整 JSON 快照。页面会在该消息下方显示“开始战斗”。
4. 点按钮预览双方、位置、资源、技能、装备、状态与背包。校验会拦截未知引用、错误栏位、非法资源和重叠站位，并列出与上次战斗结算不同的资源、装备、共用背包。用户可改快照 JSON；本场以改后的快照为准。
5. 玩家方在四格指令区选择技能、道具、移动或其他行动，点选目标后确认；结束玩家阶段后，敌方按规则行动。胜败或中断都会生成报告。战后可手动拾取战场掉落武器和已倒下敌人剩余的道具；即使敌人在较早回合倒下，剩余道具也保留到战斗结束。仍装备在身上的防具和武器不会自动进入背包。复制完整报告给剧情 AI 续写。
6. 下一场的初始值仍以剧情 AI 新提交的快照为准。扩展保留上次结算供预览比对。

## 内容制作

“可视化编辑”可切换内容包和类别，选择已有条目继续修改，也可新建技能、道具、装备、状态、我方角色与敌人模板。角色模板可设置建议站位、属性、生命/精力/法力及自定义资源、技能、装备、最多五件饰品、初始拘束和状态；敌人还可配置个人道具及 AI 策略。我方道具仍在战斗快照的共用背包中。技能的装备与状态条件、施加拘束等效果，以及装备授予技能，都按名称选择；保存时自动写入对应 ID。自定义资源与标签仍填写其键名。编辑已有条目时，表单未展示的原有字段会保留。“批量导入”可上传或粘贴一个 `turn-battle-pack/v1` JSON 包，先预览和校验再导入；一个包含多个条目的包就是一批内容。包在全局安装，角色卡绑定决定当前卡能用哪些内容。条目 ID 格式为 `包ID:条目ID`。

每个条目可填写“剧情介绍”，用于描述技能动作、装备外观、道具使用方式或状态表现。数值、释放条件与效果仍由规则字段决定。写卡助手世界书会指导生成器同时填写介绍和规则。剧情提示词列出角色卡绑定条目及其引用的介绍；战斗报告附上本场用过的技能与道具，以及当前装备和状态的介绍。

我方角色预设放在内容包的 `allies` 数组，敌人预设放在 `enemies` 数组。可在“角色卡绑定”按整包、类别或条目启用。我方预设是给剧情 AI 和写卡助手参考的建议值；开战仍由剧情 AI 根据当前剧情变量提交完整快照，并在预览中确认，不会用模板覆盖已变化的血量、装备或背包。

单独启用角色预设时，它引用的技能、装备、状态和道具也会进入可用目录。剧情中学会或失去技能、取得或失去装备、换装时，先更新角色卡自己的剧情变量；下一次开战，剧情 AI 把完整的当前技能、装备、饰品、状态、资源和背包写入 `TURN_BATTLE_REQUEST`。预览会显示与上次结算的差异，也允许手动改快照。本场以确认后的快照为准，战后再把报告里的最终状态同步回剧情变量。新的技能或装备 ID 必须先在内容包定义并绑定，不能只在快照里临时写入。

“设置与提示词”可导出酒馆 World Info JSON，给写卡助手使用。世界书指导它生成内容包和角色卡变量到开战快照的映射，扩展仍会校验生成结果。

仓库内也附有 [`examples/写卡助手世界书.json`](examples/写卡助手世界书.json)，可直接在 SillyTavern 的世界书界面导入。此文件由 `npm run build:worldbook` 从内置内容重新生成。

## 当前规则

- 玩家方整队先行动，随后敌方整队。每个角色每轮基础 1 行动点，效果可增加行动点。
- 双方前后排位置上限可设置。只要一方还有前排成员，普通近战不能攻击其后排。移动花费 1 行动点。
- 敌方前排已无站立敌人时，玩家前排可花 1 行动点进入敌方前排空位，并持续站在那里；其他玩家前排也可进入剩余空位。占据者仍保护我方后排，敌方后排在占据期间不能前移或突入。占位后，带 `melee` 标签、原本只能选前排的近战技能也能攻击敌方后排；释放前提仍须满足。玩家可再次花行动点移回我方空位。
- `疾风刺` 要求手、脚自由，持匕首或短剑，敌方前排有空位；可打前后排单体，突入敌前排直至己方阶段结束。可借额外行动点在突入期间继续攻击后排。
- `火球术`、`火雨术`、`除你武器` 要求嘴巴自由且武器栏持法杖或法术书。法术卷轴是消耗道具。
- 拘束占独立部位，可封锁带相应标签的技能；挣扎消耗行动及设定资源，按成功率移除拘束。掉落武器可在原位置花 1 行动拾起；战后手动拾取到装备收获记录。
- 技能条件可检查自身或目标有无指定装备、装备栏或状态；效果可击落装备或暂时封锁装备。Buff 和装备可提供额外行动点，每单位每轮最多执行 4 次行动。
- 技能已有释放前提，例如手部或嘴巴自由、持有指定装备、有无状态；这些条件在行动时检查。Buff 可设置持续阶段、同来源叠加上限、属性加成、命中率修正和额外行动点。`blockedTags` 会封锁一组带相同标签的技能或道具，例如 `chant` 会禁用所有需要咏唱的技能，`move` 还会禁止普通移动。`suppressedSkills` 是可选的指定技能 ID 封锁；`skills` 可临时授予技能。技能和道具可按成功率施加或解除 Buff，也可直接改变任意已定义资源、造成物理或魔法伤害、增减行动点、施加拘束或影响装备。属性加成随层数叠加；命中率与额外行动点目前按状态存在与否计算一次。
- 例如束缚状态可封锁 `hand`、`move` 标签，并授予自定义挣脱技能；不需要手部的口部魔法仍可使用。具体封锁哪几项技能可在 `suppressedSkills` 填 ID。自动每回合掉血或回血、受击触发、按条件执行的 Buff 效果目前尚未实现。
- 敌方可使用个人道具；规则 AI 支持技能优先顺序、道具优先顺序，生命较低时优先治疗。
- 伤害分物理和魔法。生命为 0 是倒下，不自动死亡。

## 验证和限制

运行 `npm test` 可执行规则与格式测试。此版本尚未在用户的 SillyTavern 实例中完成浏览器实测。请先用测试角色卡验证消息按钮、模板加载、世界书导入以及战斗存档。内容包的复杂条件、敌方 AI 策略与界面编辑能力会继续扩展。
