# 基础西幻职业技能目录

内容包：`fantasy-basic`，87 个技能、32 个状态、7 个我方职业模板、5 个怪物模板。

角色只会在战斗菜单里看到本次快照已经学会的技能和装备授予的普通攻击。剧情中新学的技能仍需把对应 ID 写入下一场快照。

## 武器普通攻击

- **长剑斩击**（`fantasy-basic:weapon/sword-slash`）：以长剑向前挥出一击。
- **战斧劈砍**（`fantasy-basic:weapon/axe-swing`）：抡起战斧向目标劈落。
- **钉锤打击**（`fantasy-basic:weapon/mace-hit`）：挥动钉锤重击目标。
- **短弓射击**（`fantasy-basic:weapon/bow-shot`）：搭箭射向可见的敌人。
- **匕首刺击**（`fantasy-basic:weapon/dagger-stab`）：贴近目标迅速刺出匕首。
- **法杖敲击**（`fantasy-basic:weapon/staff-hit`）：以法杖近身敲击。
- **圣徽拍击**（`fantasy-basic:weapon/symbol-hit`）：以手持圣徽近身击打。

## 战士／狂战士／圣骑士共用武技

- **强力打击**（`fantasy-basic:martial/power-strike`）：蓄力后挥出沉重的一击。
- **横扫**（`fantasy-basic:martial/cleave`）：横向挥动武器，攻击敌方前排。
- **破甲斩**（`fantasy-basic:martial/armor-break`）：瞄准护甲接缝，留下明显破绽。 → 破甲（基础成功率 75%）
- **缴械打击**（`fantasy-basic:martial/disarm`）：击向握持武器的手，试图使武器脱落。
- **防御架势**（`fantasy-basic:martial/guard`）：稳住身形，准备承受下一轮攻势。 → 守势
- **战吼**（`fantasy-basic:martial/battle-cry`）：高声鼓舞同伴，提升整队战意。 → 战意
- **破绽追击**（`fantasy-basic:martial/finish`）：抓住敌人护甲破绽补上重击。
- **调息**（`fantasy-basic:martial/recover`）：稳住呼吸，恢复少量精力。

## 射手／刺客共用技巧

- **迅捷一击**（`fantasy-basic:agile/quick-attack`）：抓住空隙迅速出手。
- **扰乱**（`fantasy-basic:agile/disorient`）：虚晃一击，使目标露出破绽。 → 露出破绽（基础成功率 70%）
- **阻行打击**（`fantasy-basic:agile/hamstring`）：攻击目标腿部，试图限制移动。 → 缚足（基础成功率 55%）
- **调整呼吸**（`fantasy-basic:agile/recover`）：暂缓出手，恢复少量精力。
- **破绽一击**（`fantasy-basic:agile/decisive-attack`）：精准攻击已经失去平衡的目标。

## 当前规则范围

- 伤害按技能威力、物攻／魔攻倍率和目标防御确定，不使用骰子表达式；命中与状态施加使用明确的百分比。
- Buff / Debuff 的属性变化、命中修正、技能封锁与额外行动点由插件计算。持续两阶段的状态通常覆盖目标下一次行动，随后到期。
- 中毒当前降低攻击属性，不会每回合自动扣血。治疗为固定恢复量；自动触发、反击和通用标签净化尚未加入规则引擎。
- 每名职业模板有两项永久被动状态，开战快照中的 `statuses` 负责携带。
